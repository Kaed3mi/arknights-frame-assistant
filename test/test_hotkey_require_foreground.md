## 集成测试

### 流程：后台窗口化全屏防误触发

> 涉及模块：`HotkeyService`、`SettingsService`、`GameTarget`、`GuiManager`。

- [ ] **前置**：明日方舟窗口化全屏运行，AFA 热键已启用；勾选前台限制并应用。开启悬停操作并应用，以验证前台限制的优先级。
- [ ] **操作**：打开窗口化记事本，使其处于前台，鼠标停在露出的游戏客户区，按暂停、技能等已绑定键盘快捷键。
- [ ] **预期**：AFA 不执行游戏动作、不抢回焦点；记事本正常接收键盘输入。
- [ ] **操作**：保持记事本在前台、鼠标在露出的游戏客户区，按绑定的鼠标侧键、中键与滚轮快捷键。
- [ ] **预期**：AFA 不执行动作、不激活游戏；滚轮与鼠标按键正常交由当前应用/系统处理。
- [ ] **操作**：将鼠标移回记事本，再按同一组快捷键。
- [ ] **预期**：AFA 不干预；应用输入正常。
- [ ] **操作**：切回游戏前台，鼠标在游戏客户区，测试键盘、鼠标与滚轮快捷键。
- [ ] **预期**：原有游戏功能正常触发。
- [ ] **操作**：保持游戏在前台，将鼠标移到任务栏或其他窗口，测试已绑定的鼠标与滚轮快捷键。
- [ ] **预期**：客户区外不触发 AFA 鼠标动作，任务栏与其他窗口可正常点击和滚动。

### 流程：开关关闭与持久化

- [ ] **操作**：关闭前台限制、开启悬停操作并应用；使其他应用处于前台，将鼠标移到游戏客户区，按键盘或鼠标快捷键。
- [ ] **预期**：恢复原有悬停操作行为，可激活游戏并执行动作。
- [ ] **操作**：关闭前台限制且关闭悬停操作并应用，重复上述操作。
- [ ] **预期**：键盘快捷键要求游戏在前台；鼠标快捷键保留原有客户区悬停行为。
- [ ] **操作**：重新开启前台限制并保存，退出后重新启动 AFA。
- [ ] **预期**：开关保持勾选，后台键盘和鼠标动作均被限制。
- [ ] **操作**：修改开关但使用取消放弃修改，重新打开设置。
- [ ] **预期**：开关和运行时策略都保持上一次已保存的值。

### 流程：启用/禁用热键快捷键与自定义按键

- [ ] **前置**：配置「启用/禁用热键」快捷键和一个自定义单击按键，前台限制开启并应用。
- [ ] **操作**：其他应用在前台、鼠标悬停游戏时，分别按这两个快捷键。
- [ ] **预期**：热键启用状态不变；自定义单击不执行，游戏不抢回焦点。
- [ ] **操作**：游戏在前台时，依次禁用和重新启用热键，再触发自定义按键。
- [ ] **预期**：状态切换与自定义单击正常。

### 流程：失焦时的松开收尾

- [ ] **前置**：开启关卡守卫并应用，在游戏的非关卡界面使用一个会被 AFA 拦截后透传的游戏按键。
- [ ] **操作**：按住该键，通过 Alt+Tab 切到记事本，再松开该键。
- [ ] **预期**：按住周期正常结束；记事本无持续重复输入，切回游戏后该键可再次使用。
- [ ] **操作**：在游戏中按住「按住开局暂停」快捷键，切出游戏再松开。
- [ ] **预期**：等待/按住状态能结束；AFA 不因收尾激活游戏或在后台发送新的游戏动作。
- [ ] **操作**：在游戏中按住「松开时暂停」快捷键，切到其他应用再松开。
- [ ] **预期**：不因松开动作激活游戏；再次回到游戏后快捷键可正常使用。

### 异常路径

- [ ] **操作**：快速切换前台应用并连续按已绑定快捷键。
- [ ] **预期**：AFA 不主动将失焦游戏拉回前台，不出现卡键或持续输入。
- [ ] **操作**：关闭游戏窗口后，在其他应用中按已绑定快捷键。
- [ ] **预期**：不出现窗口不存在异常；应用输入正常。如果已配置自动退出，AFA 按既有设置退出。
- [ ] **操作**：如已安装多个区服，同时运行两个客户端，在两者之间切换后测试快捷键。
- [ ] **预期**：使用前台客户端对应的按键映射；切到非游戏应用后快捷键不触发。未安装多个区服时记录跳过原因。
