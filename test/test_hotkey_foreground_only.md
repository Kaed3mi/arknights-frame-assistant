## 集成测试

> 涉及模块：HotkeyContext、HotkeyService、GameTarget、KeyForward、HoldGuard。

### 流程：后台全屏不触发

- [ ] **前置**：进入可安全操作的关卡，配置键盘、鼠标键、滚轮热键和启用/禁用切换键。
- [ ] **操作**：分别使用全屏、无边框全屏（如支持）和窗口化，将焦点切到记事本或浏览器，鼠标停在仍可见的游戏区域，逐个触发已配置热键。
- [ ] **预期**：游戏不执行 AFA 动作、不抢焦点、不弹出设置切换提示；前台应用正常接收对应输入。
- [ ] **操作**：鼠标移到前台应用、任务栏和桌面，重复上述操作。
- [ ] **预期**：前台应用、任务栏和桌面输入正常，不触发 AFA 动作。

### 流程：前台操作与功能分组

- [ ] **操作**：主动点击游戏获取焦点，在常规作战、快捷操作、卫戍协议组分别触发代表性键盘、鼠标和自定义按键。
- [ ] **预期**：符合原有分组与关卡守卫规则的动作正常触发。
- [ ] **操作**：游戏保持焦点，鼠标移到游戏窗口之外，分别触发键盘、鼠标和滚轮热键。
- [ ] **预期**：键盘热键按原规则生效，窗口外鼠标和滚轮不触发 AFA 动作。

### 流程：失焦松键与快速切换

- [ ] **操作**：在游戏内按住一个会被拦截的键或按住型鼠标热键，Alt+Tab 切走后松开，再切回游戏。
- [ ] **预期**：正常释放按键，无持续按住或卡键，不抢回焦点。
- [ ] **操作**：配置松开时暂停，按下后切走再松开；反复快速切换前台并触发热键。
- [ ] **预期**：失焦后的松开不执行暂停动作，不自动激活游戏；回到游戏后热键正常。

### 异常路径

- [ ] **操作**：最小化游戏、退出游戏，在其他应用触发相同热键；随后重新启动游戏并主动获取焦点。
- [ ] **预期**：后台与窗口不存在时不触发、不等待激活、不报错；重新获取焦点后恢复正常。
- [ ] **前置**：使用旧配置，其中保存了 HoverOperate=1。
- [ ] **操作**：启动修复版，切走游戏后悬停并触发热键，再应用设置、重启。
- [ ] **预期**：旧值始终不能恢复失焦触发，设置保存与加载正常。
